# Codex Android

Native Android workspace for managing GitHub repositories and agent-assisted development from a phone.

## Milestone 1
- Kotlin + Jetpack Compose
- GitHub credential stored with Android encrypted preferences
- Repository browser for repositories visible to the authenticated account
- Search and repository selection foundation
- CI unit tests + debug APK

## Security
Never commit GitHub/OpenAI tokens.

## Codex
This project is an independent Android client. It does not impersonate the official OpenAI Codex app. Codex Cloud will be integrated only through supported OpenAI interfaces.
